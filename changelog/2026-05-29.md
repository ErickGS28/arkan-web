# Changelog — 29 Mayo 2026

---

## Resumen del día

Sesión de diagnóstico y corrección de producción. Se resolvió el problema del nginx default en el dominio, se corrigió el Dockerfile del frontend (estaba configurado para sitio estático en lugar de SSR), se agregó la sección de Distribución que faltaba en las páginas de marca, se corrigieron los anclas del navbar, y se migró el fetch de categorías de server-side a client-side para que el browser consuma el API directamente (igual que el panel admin).

---

## 1. Nginx default en el dominio

- **Causa:** el dominio `arkangroup.mx` en Dokploy tenía `Port: 80` en lugar del puerto real del contenedor Astro.
- **Fix:** cambiar a `Port: 4321` en la sección Domains del servicio frontend en Dokploy.

---

## 2. Dockerfile — SSR vs estático

- **Causa:** el Dockerfile original copiaba el `dist/` a nginx como sitio estático, ignorando el servidor Node.js que genera Astro SSR.
- **Fix:** segunda etapa cambiada de `nginx:alpine` a `node:22-alpine`, corriendo `node ./dist/server/entry.mjs` con `HOST=0.0.0.0` y `PORT=4321`. Dependencias de producción instaladas con `npm ci --omit=dev`.

---

## 3. Navbar — anclas rotas

- **`#lookbook` (Categorías):** `BrandCategories.astro` no tenía `id="lookbook"`. Agregado.
- **`#cta` (Distribución):** `BrandCta.astro` existía pero nunca fue incluido en `BrandPage.astro`. Agregado al layout.

---

## 4. Sección Distribución — `BrandCta`

- Agregado `BrandCta` al layout `BrandPage.astro`.
- Agregado campo `cta` a la interfaz `Brand` y datos para las 3 marcas (Aruba, Bakari, Black Bash) con texto y link directo a WhatsApp.

---

## 5. Fetch de categorías — server-side → client-side

- **Causa:** el fetch SSR en `aruba.astro`, `bakari.astro`, `black-bash.astro` fallaba con `ENOTFOUND` porque el contenedor Docker no puede alcanzar `api.arkangroup.mx` desde adentro (hairpin NAT bloqueado en Dokploy).
- **Fix:** fetch movido a un `<script define:vars>` client-side en `BrandCategories.astro`. La página carga con datos estáticos inmediatamente; el browser reemplaza los sliders con las imágenes del admin tras la carga — mismo patrón que el proyecto `conectate`.
