- **Fondo negro a los lados**: `.article` tenía `max-width: 760px` centrado pero el body es `#0A0A0A`. Fix: `.article` ahora es `width: 100%` y el contenido se centra con `.article-inner { max-width: 720px }`

- **Elementos añadidos**: `h3`, `strong`, `em`, `a`, `ul`, `ol`, `li`, `blockquote`, `code`, `pre`
- **Responsive**: breakpoints a 900 / 768 / 480 px con tamaños ajustados

## 6. Fix cookies cross-origin — `auth.controller.ts` (backend)

**Problema:** con `SameSite=Strict` en producción, el browser bloqueaba el envío de la cookie al hacer requests desde `localhost` hacia `api.arkangroup.mx`. El login devolvía 201 pero `/auth/validate` nunca recibía la cookie → redireccionaba de vuelta a login.

**Fix:** `sameSite: 'none'` en producción (requiere `secure: true`, ya aplicado). El CORS sigue restringiendo orígenes específicos, así que la seguridad se mantiene.

```ts
// antes
sameSite: process.env.NODE_ENV === 'production' ? 'strict' : 'lax'
// ahora
sameSite: isProd ? 'none' : 'lax'
```
