# Changelog — 7 Junio 2026

---

## Resumen del día

Se agregó **generación de contenido de blog con IA (Google Gemini)** al panel admin. Un
nuevo botón "Generar contenido" en las páginas de crear y editar post redacta título,
resumen y cuerpo completos, siempre alineados con la filosofía editorial de Arkán Group.
La API key vive solo en el backend (NestJS) y nunca se expone al navegador.

---

## 1. Backend (`arkan-service`) — endpoint de generación

### `AiService` — `src/modules/blog/ai.service.ts`
- Llama a la REST API de Gemini con `fetch` global (Node 22, **sin dependencias nuevas**).
- Salida estructurada vía `responseMimeType: application/json` + `responseSchema`
  → `{ title, excerpt, content }`. El `content` es HTML limpio restringido a las etiquetas
  del toolbar de Quill (`h2, h3, p, strong, em, ul, ol, li, blockquote, a`).
- **System prompt con la filosofía de Arkán:** apostar por lo nacional 🇲🇽 (entendido como
  fortalecer al distribuidor/mercado mexicano), calidad real sobre precio barato, denim con
  identidad, enfoque B2B. Incluye las 3 marcas (Aruba, Bakari, Black Bash).
- **Matiz de marca:** el prompt aclara que "lo nacional" NO implica tela mexicana; Arkán
  distribuye denim colombiano de calidad (Aruba). La IA nunca debe escribir en contra del
  origen colombiano — el enemigo es la baja calidad.
- Si falta `GEMINI_API_KEY` → `ServiceUnavailableException` (patrón de `CloudflareService`).
  Errores de red/upstream → `BadGatewayException`.

### Endpoint y wiring
- `POST /blog/generate` (`@UseGuards(SessionGuard)`), body `{ topic, title? }`.
- `GenerateContentDto` con `class-validator`.
- `AiService` registrado en `BlogModule`.

### Variables de entorno
```
GEMINI_API_KEY=...
GEMINI_MODEL=gemini-2.5-flash
```
Agregadas a `.env` y `.env.example`.

> **Pendiente de deploy:** agregar `GEMINI_API_KEY` (y opcionalmente `GEMINI_MODEL`) a las
> variables de entorno del servicio backend en Dokploy.

## 2. Frontend (`arkan-web`) — botón "Generar contenido"

- Tarjeta lateral oscura con textarea de **tema/instrucción** + botón en
  `admin/blog/new.astro` y `admin/blog/edit.astro`.
- Al generar: `POST /blog/generate` con `credentials: 'include'`; rellena título, resumen y
  carga el contenido en el editor Quill.
- **Confirma antes de sobrescribir** si ya hay título, resumen o contenido.
- Estado de carga (spinner en el botón) y toasts de éxito/error, reusando los estilos del
  panel (Syne/Bebas, blanco y negro).
